# 防水保温建材销售探索性数据分析

这是对中国无锡一家建材批发商 **2007–2026 年销售流水**（94,550 行 × 18 列）的探索性数据分析（EDA）项目。分析链路：**数据治理 → 单变量分析 → 多维交叉分析 → 业务建议**，产出可复用的 Jupyter notebook 与可视化图表。

> 本仓库为 **脱敏公版**：数据已匿名化处理，不含真实客户、单据信息，可安全公开。真实数据仅存于本地，不随仓库分发。

## 数据脱敏说明

公开数据为 `public_data/sales_anonymized.xlsx`（94,550 行 × 17 列，Sheet 名 `sales`）。脱敏规则：

| 字段 | 处理方式 |
|---|---|
| 客户名称 | 假名化编号（客户001…）；真实映射表仅存本地，绝不公开 |
| 商品单价 / 折后单价 | 按商品组（名称+规格+编码）共享随机因子扰动，同商品同规格价格一致 |
| 出货数量 | 逐行加减扰动（非乘法） |
| 已付金额 / 欠款金额 | 逐行随机因子扰动 |
| 单据号 | 顺序替换（SO-000001…） |
| 备注 | 删除 |

**数学关系保持**：扰动后重算 `合计 = 折后单价 × 数量`、`欠款 = 合计 − 已付`，口径与原数据一致。

## 分析框架

1. **数据治理与清洗**：缺失值填充（规格按同商品匹配、客户缺失判零售）、异常值修正（单价异常、8825 年脏日期、已付负值）、口径统一（合计/欠款关系重算）
2. **单变量分析**：时间序列（年度趋势 + 季节性）、客户帕累托分析、订单结构、品类结构
3. **交叉分析**
   - 客户 × 品类：交叉购买画像与品类联动（交叉销售机会）
   - 品类 × 时间：增长/衰退贡献分解、季节模式
   - 客户 × 欠款：四象限风险分级（营收 × 欠款率）
   - 时间 × 客户流：留存 / 新客 / 流失分解、同期群留存、客户生命周期
4. **业务建议**：客户分级管理与赊销额度、第二品类培育、保量策略（存量房翻新）、工程大单维护

## 简要核心结论摘要

- **营收走势**：累计营收约 1.04 亿元；2017/2018 年达峰值（约 1,196 万/年）后随房地产周期回落，**2023 → 2025 下滑 29.0%**
- **品类高度集中**：邓禄普系列一家占 **73.9%** 营收，TOP3 品类合计 90.2%；本轮下滑 77.5% 由其贡献（结构性下滑，全品类普跌）
- **客户高度集中**：前 20% 客户（259 家）贡献 **93.2%** 营收，同时持有 90.2% 欠款
- **应收风险**：119 家风险客户（9.2%）持有 **49.7% 欠款**（约 813 万），应收管控空间大
- **订单结构**：≥1,000 元订单仅占 29.2% 数量，却贡献 83.2% 营收；工程大单（≥1 万元）1,069 笔 / 24.3% 营收
- **客户流失**：新客占比从 2014 年 75.7% 降至 2025 年 6.1%，近半数客户仅活跃 1 年（营收占比 2.3%）
